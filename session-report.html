UI / Design Improvements

UI

1. Professional Button Redesign (Sitewide)

Replaced all rounded, AI-looking buttons across the entire website (all sections, headers, landing page, modals) with clean, professional, squared-edge buttons. Removed the generic pill-shaped button styling and replaced it with a modern, minimal aesthetic that feels premium and hand-crafted.

Files: index.css, all section components
UI

2. Navbar Hover Underline Animation

Implemented a smooth animated underline hover effect on all desktop navbar links. The underline slides in from the left on hover and stays active on the current page. The underline length is precisely matched to the text/word length (not the full clickable padding area), achieved by wrapping the label text in a relative inline span.

Files: src/components/Navbar.jsx

Bug Fixes

FIX

3. Modal Close Button Positioning

Fixed the Student Login modal's close (✕) button. It was previously floating outside the modal border. Restructured the modal so that the logo, title, form, and close button are all wrapped inside a single bordered container. The close button is now smartly positioned inside the top-right corner of the modal border.

Files: src/pages/StudentLogin.jsx
FIX

4. Admin Login Link — Modal Overlap Bug

Fixed a critical UX bug where clicking "Administrator Login" inside the Student Login popup would navigate to the admin login page, but the Student Login modal would remain open and visible in the foreground. Added an onClick handler to explicitly close the modal before navigating away.

Files: src/pages/StudentLogin.jsx
FIX

5. Logo Link — Modal Persistence Fix

Same fix applied to the RBT Mission logo link at the top of the login modal. Clicking the logo now correctly closes the popup before navigating to the homepage.

Files: src/pages/StudentLogin.jsx

New Features Implemented

FEATURE

6. Student Signup Modal (New Component)

Built a brand-new Student Signup modal component (StudentSignup.jsx) with two registration methods:

a) Google Auth Signup: One-click registration using Google. Automatically creates a Firestore profile with basic student access.

b) Email & Password Signup: Manual registration with form fields for Full Name, Email, Password, and Confirm Password. Includes real-time validation — passwords must match and be at least 6 characters. Prevents submission on mismatch.

The modal matches the existing premium dark design system (glassmorphism, animated gradients, smooth transitions).

Files: src/pages/StudentSignup.jsx (NEW), src/context/AuthContext.jsx, src/App.jsx
FEATURE

7. Navbar — Separate Login & Sign Up Buttons

Updated the Navbar to show two distinct buttons for unauthenticated users:

• Login — subtle ghost-style button (text only, hover highlight)

• Sign Up — prominent green CTA button (primary action)

This applies to both desktop and mobile navigation. Both modals support seamless switching between Login ↔ Sign Up via footer links ("Don't have an account?" / "Already have an account?").

Files: src/components/Navbar.jsx, src/App.jsx
FEATURE AUTH

8. Firebase Email/Password Signup Backend

Created a new signupStudent(email, password, name) function in the Auth Context. It uses Firebase's createUserWithEmailAndPassword to register the user, then creates a Firestore document in the students collection with their profile data, role, and auto-generated RBT ID. All new signups are granted Basic Student Access by default.

Files: src/context/AuthContext.jsx
FEATURE SYSTEM

9. RBT Student ID System (RBT ID)

Implemented a standardized, unique Student Identification system. Every student who registers on the platform is automatically assigned a permanent, privacy-compliant RBT ID.

Format Breakdown:

Part Value Meaning
RBT Institution Code Identifies RBT Mission Learning
26 Cohort Year Year of account creation (2026)
G / E / B Auth Method G = Google, E = Email, B = Batch
- Separator Readability
XXXXXX Unique Hash 6-char alphanumeric from Firebase UID

Examples:

RBT26G-A1B2C3 — Student signed up via Google

RBT26E-X9Y8Z7 — Student signed up via Email

RBT26B-Q1W2E3 — Batch student (enrolled)

Visibility: The RBT ID is displayed on the Student Dashboard (under the student's name) and is visible to Administrators in the Manage Students panel.

Files: src/context/AuthContext.jsx
